# StudioTwin web examples

Creative and 3D web projects built by AI agents with the **[StudioTwin MCP](https://studiotwin.ai/mcp)**: concepts, meshes, rigs, materials, skies and sound, all generated from prompts and assembled into real-time web experiences.

## Get started

```bash
npx skills add realtwin/studiotwin-mcp-skill
```

Then connect StudioTwin MCP at **[studiotwin.ai/mcp](https://studiotwin.ai/mcp)**. Works with Claude Code, Cursor, Codex, Gemini and any agent that supports skills.
